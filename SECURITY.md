# Security / Sécurité

For suspected vulnerabilities use GitHub private vulnerability reporting on this repository when available; otherwise email contact@hugoviaud.fr with a minimal fictional reproduction. Do not publish exploit details, private measurements or secrets in a public issue. No response SLA is promised.

Scope: web comparator source and static assets in this repository. This edition has no server, accounts, payments, data submission or secrets. Hosting configuration is maintained separately. No security audit or certification is claimed. Use supported browsers, keep your hosting secure and preserve local-only input processing.
