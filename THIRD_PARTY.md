# Assets and dependencies

No runtime npm dependencies, remote font calls or external icon library. Browser ES modules and local files only. Geometry tests use Node's built-in assert module; the link checker uses Python's standard library.

| Component | Licence | Files |
|---|---|---|
| Original BikeGeo web code, diagrams, logos and launch visual | MIT | LICENSE |
| Manrope variable font, embedded unchanged | SIL OFL 1.1 | public/manrope.ttf; public/licenses/manrope-OFL.txt |
| Lucide SVGs (Static 1.52.0 source) | ISC; included Feather MIT attribution | public/icons/; public/licenses/lucide-ISC.txt |

BikeGeo wordmark outlines use Manrope. Font and icon notices are retained in full; their licences are not replaced by MIT.

| Icon | Use / Justification |
|---|---|
| arrow-left-right | Compare A/B; reciprocal relation, explicit Δ = B − A |
| move-horizontal | ΔX only; horizontal displacement |
| move-vertical | ΔY only; vertical displacement |
| languages | FR/EN interface language, not country/currency |
| sun | Switch to light theme; accessible label names the destination |
| moon | Switch to dark theme; accessible label names the destination |

Decorative icons have empty alt text and controls retain labels. A is hollow, B filled; colour is not the only distinction. No invented trust/certification badges.
