# Contributing / Contribuer

Open an issue or pull request with a concrete problem and fictional reproduction inputs. Never submit client measurements, personal data, tokens or credentials. Keep this edition web-only and free; no Android, billing, analytics or catalogue scraping additions.

Run `node tests/geometry.test.mjs` and `python3 scripts/check-static.py`. For UI changes verify FR/EN, light/dark, a narrow viewport, keyboard focus, invalid input, copy, clear and stale-result hiding. Explain geometry changes with an independent analytical example and updated limits. Preserve asset licences. Update the comparator script URL content hash whenever app.js changes.
